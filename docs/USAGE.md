# 风月 · 使用说明

## 下载与安装

到本仓库 [Releases](../../releases) 页面下载最新版：

| 平台 | 下载哪个 |
|---|---|
| Windows | `FengYue-x.y.z-N-Setup.exe`（双击，按提示装）|
| Android | `FengYue-x.y.z-N-arm64-v8a.apk`（绝大多数机型都是这个）|

安卓若提示「未知来源」，允许一次即可。

## 音乐

音乐有两种玩法：

**① 用酷狗账户**

在音乐页登录**酷狗账户**后即可直接播放。酷狗对新登录用户常有会员权益赠送，
具体以**酷狗自己的规则**为准（软件不参与、也不保证）。

**② 导入音源插件**

支持导入 **lx（落雪）生态的 JS 音源插件**，也支持**本软件自己的 JSON 插件**。
插件决定「能听哪些歌、从哪取」——想听更多源就多导入几个。

> 导入入口就在音乐模块里（**具体位置以软件内为准**）。

## 短剧

**开箱即用**：打开短剧就能浏览、播放，**不需要配置、不需要先去设置里做什么**。

换站源 / 用更进阶的能力，有个隐藏入口：

> **短剧浏览页 → 左上角的平台名字 → 连点 4 次（2 秒内）**

首次进去需要设一个密码；里面可以开启**无密码模式**，之后点 4 次确认一下即可。

## 数据存在哪

- 数据都在 **`<你的盘符>:FengYue`** 下（例如 `D:FengYue`）：音乐在 `Music`、短剧在 `Drama`；
- 路径可在设置里修改；
- ⚠️ **卸载软件不会删除这些数据**，要清就自己去那个目录删。

## 更新

- 软件**自动检查更新**：启动后一次，之后每 5 小时一次；
- 默认**静默下载**：发现新版本在后台下好，下完提示「已就绪」，点一下即可安装；
- 也可手动：「设置 → 关于软件 → 软件更新 → 检查更新」；
- 不想自动下载？把那里的「**静默下载更新**」关掉，就只提示你有新版本。

## 常见问题

**更新/下载慢或失败？**
国内直连 GitHub 不稳定。软件内置了加速节点、失败会自动换。仍不行稍后再试。

**想反馈问题？**
到 [Issues](../../issues) 提，写清**版本号**（设置 → 关于软件）和**复现步骤**，会快很多。
