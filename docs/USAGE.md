## 下载与安装

到本仓库 [Releases](../../releases) 页面下载最新版：

| 平台 | 下载哪个 | 说明 |
|---|---|---|
| Windows | `FengYue-x.y.z-N-Setup.exe` | 双击，按提示装 |
| Android | `FengYue-x.y.z-N-arm64-v8a.apk` | 绝大多数机型都是这个 |

安卓装的时候如果提示「未知来源」，允许一次即可。

## 第一次打开

启动后是首页。**左侧竖栏（窄屏是顶栏）是主要入口**：

| 入口 | 里面是什么 |
|---|---|
| 主页 | 推荐内容、每日推荐 |
| 音乐 | 播放、歌单、歌词、音源 |
| 短剧 | 浏览、播放、下载 |
| 搜索 | 全局搜索 |
| 我的 | 本地媒体、收藏、历史、短剧、笔记等（以软件内为准）|

> 底部/侧边入口的**顺序可以在设置里调整**（具体在哪个分类下以软件内为准）。

## 音乐：两种玩法

**① 用你自己的酷狗账户（推荐新手）**

在音乐页登录**酷狗账户**后可以直接播放、下载。酷狗对新登录用户常常有会员权益赠送，
具体以**酷狗自己的规则**为准（软件不参与、也不保证）。

**② 导入音源插件（能力最全）**

支持导入 **lx（落雪）生态的 JS 音源插件**，也支持**本软件自己的 JSON 插件**。
插件决定"能听哪些歌、从哪取"——想听更多源就多导入几个。

## 插件怎么导入

**音乐插件**：音乐页 →「**音源**」→ 导入。支持两种：

| 类型 | 说明 |
|---|---|
| **lx JS 插件** | 从 lx 生态拿到的 `.js` 音源脚本，直接导入即可用 |
| **JSON 插件** | 本软件自己的插件格式（`.json`）|

导入后可以在列表里启用/停用、看诊断信息（加载成功与否、首个错误）。

**短剧**：不需要导入插件，也**不需要去设置里配什么**，打开就能看（详见下节）。

## 短剧怎么用

**开箱即用**：打开「短剧」就能浏览和播放，**不需要任何配置**。

想换站源 / 用更进阶的能力，有个隐藏入口：

> 在**短剧浏览页**，**左上角的平台名字连点 4 次**（2 秒内）⇒ 进入站源解锁/管理。
> 首次需要设置一个密码；设置里可开启**无密码模式**，之后点 4 次只需确认一下。

## 数据存在哪

- 数据都在 **`<你的盘符>:FengYue`** 下（比如 `D:FengYue`）；
  - 音乐相关在 `Music`，短剧在 `Drama`；
- 路径可以在「设置 → 存储管理」里改；
- ⚠️ **卸载软件不会删除这些数据**，要清就自己去那个目录删。

## 更新

- 软件会**自动检查更新**：启动后一次，之后每 5 小时一次；
- 默认**静默下载**：发现新版本会在后台下好，下完提示你「已就绪」，点一下就能装；
- 也可以手动：「设置 → 关于软件 → 软件更新 → 检查更新」；
- 不想自动下载？把那里的「**静默下载更新**」关掉，就只会提示你有新版本。

## 常见问题

**更新/下载很慢或失败？**
国内直连 GitHub 不稳定。软件内置了加速节点、失败会自动换节点。仍不行就稍后再试。

**装完打不开 / 闪退？**
先确认装的是对应架构（安卓几乎都是 `arm64-v8a`）。仍不行请到 [Issues](../../issues) 反馈。

**想反馈问题？**
到 [Issues](../../issues) 提，写清**版本号**（设置 → 关于软件）和**复现步骤**，会快很多。
