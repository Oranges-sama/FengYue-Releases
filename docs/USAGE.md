# 风月 · 使用说明

## 下载安装

到本仓库 [Releases](../../releases) 页面下载最新版：

| 平台 | 下载哪个 |
|---|---|
| Windows | `FengYue-<版本>-Setup.exe` |
| Android | `FengYue-<版本>-arm64-v8a.apk`（绝大多数机型都是这个）|

Windows 双击安装包按提示装即可；Android 允许「安装未知来源应用」后点开 APK 安装。

## 第一次打开

1. 启动后进入首页，左侧（窄屏在顶栏）是主要功能入口；
2. 音乐、短剧等模块需要先在**设置**里配置数据源；
3. 「设置 → 关于软件」里可以看到当前版本，也能检查更新。

## 功能一览

| 模块 | 说明 |
|---|---|
| 音乐 | 本地媒体库、在线播放、歌词、封面特效、歌单 |
| 短剧 | 多站源浏览、播放、下载（需在设置里选站源）|
| 插件 | 通过插件接入不同站点与服务 |
| 笔记 | 本地笔记，支持富文本 |
| 设置 | 外观、播放、下载、存储路径、更新等 |

## 数据与存储

- 数据目录在 **`<盘符>:FengYue`**（音乐放 `Music`，短剧放 `Drama`）；
- 可以在「设置」里改存储路径；
- 卸载软件**不会**删掉这些数据，需要自己清理。

## 更新

- 软件会**自动检查更新**（启动后一次，之后每 5 小时一次）；
- 默认**静默下载**：发现新版本会在后台下好，下完提示你更新；
- 也可以到「设置 → 关于软件 → 软件更新」手动检查；
- 不想自动下载？把「静默下载更新」关掉，它就只会提示你有新版本。

## 常见问题

**下载/更新很慢或失败？**
国内直连 GitHub 不稳定，软件内置了加速节点并会自动回退。若持续失败，稍后再试或检查网络。

**播放没有声音 / 画面卡住？**
先到设置里确认数据源可用；仍不行请到本仓库 [Issues](../../issues) 反馈。

**想反馈问题？**
到 [Issues](../../issues) 提，附上**版本号**（设置 → 关于软件）和**复现步骤**会好定位很多。
