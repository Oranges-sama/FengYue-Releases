# 风月 · 使用说明

## 下载与安装

到本仓库 [Releases](../../releases) 页面下载最新版：

| 平台 | 下载哪个 |
|---|---|
| Windows | `FengYue-x.y.z-N-Setup.exe`（双击，按提示装）|
| Android | `FengYue-x.y.z-N-arm64-v8a.apk`（绝大多数机型都是这个）|

安卓若提示「未知来源」，允许一次即可。

## 主界面

打开软件后进入**主页**，主入口是：

| 入口 | 说明 |
|---|---|
| 主页 | 首页内容 |
| 类别 | 按分类浏览 |
| 演员 | 按演员浏览 |
| 我的 | 个人相关（本地、收藏、历史、笔记、插件等）|

> 入口会按你的功能开关增减，**以软件内实际显示为准**。

## 插件

本软件是**插件机制**，插件负责对接各个站点与服务：

- 插件是**本软件自己的格式**（JSON）；
- 通过插件接入不同的站点 / 数据源。

⚠️ 它与下面的「音乐音源」**不是同一套东西**，别混。

## 音乐

音乐有两条独立的路子：

**① 酷狗账户**

在音乐页登录**酷狗账户**后即可直接播放。酷狗对新登录用户常有会员权益赠送，
具体以**酷狗自己的规则**为准（软件不参与、也不保证）。

**② 音源插件（lx 生态的 JS 插件）**

音乐支持导入 **lx（落雪）生态的 `.js` 音源插件**，插件决定「能听哪些歌、从哪取」。

> 注意：音乐用的是 **JS 音源插件**，**不涉及**上面那套本软件的 JSON 插件。

## 短剧

**开箱即用**：打开短剧就能浏览、播放，不需要配置。

想换站源 / 用更进阶的能力，有两个隐藏入口：

> · **短剧页长按**
> · **短剧浏览页左上角的平台名字，连点 4 次（2 秒内）**

首次进去需要设一个密码；里面可以开启**无密码模式**，之后确认一下即可。

## 数据存在哪

- 数据都在 **`<你的盘符>:FengYue`** 下（例如 `D:FengYue`）：音乐在 `Music`、短剧在 `Drama`；
- 路径可在设置里修改；
- ⚠️ **卸载软件不会删除这些数据**，要清就自己去那个目录删。

## 更新

- 软件**自动检查更新**：启动后一次，之后每 5 小时一次；
- 默认**静默下载**：发现新版本在后台下好，下完提示「已就绪」，点一下即可安装；
- 下载前会**并发测速、自动挑最快的节点**（顶部显示流光进度条，下载时显示进度）；
- 也可手动：「设置 → 关于软件 → 软件更新 → 检查更新」；
- 不想自动下载？把那里的「**静默下载更新**」关掉，就只提示你有新版本。

## 常见问题

**更新/下载慢或失败？**
国内直连 GitHub 不稳定。软件内置了加速节点，会**测速选最快**、失败自动换。仍不行稍后再试。

**想反馈问题？**
到 [Issues](../../issues) 提，写清**版本号**（设置 → 关于软件）和**复现步骤**，会快很多。
