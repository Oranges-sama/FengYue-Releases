## 专业版是什么

专业版是对开发者的**赞助支持**，用来解锁若干进阶能力。
它不是会员制，**没有订阅、没有到期**——一次支持，长期可用。

## 怎么开启

1. 在软件里进入**专业版入口**（设置里带「专业版」标记的地方，或按提示弹出的引导）；
2. 按提示完成赞助；
3. 回来后**点「我已赞助」** ⇒ 立即解锁，**不需要等待审核、不需要联系谁**。

## 哪些功能需要专业版

目前这些能力是专业版专属（**以软件内实际显示为准**，不同版本可能调整）：

| 功能 | 说明 |
|---|---|
| **音乐下载** | 把歌曲下载到本地 |
| **短剧下载** | 把短剧下载到本地（含下载总开关）|
| **短剧其他平台** | 使用内置站源之外的其它平台 |
| **创建插件** | 自己创建/生成插件 |
| **激活插件** | 激活需要授权的插件 |
| **外部播放器** | 交给外部播放器去播 |
| **应用伪装** | 把软件伪装成别的样子（笔记等）|

> 没解锁时点这些功能，会弹出专业版引导 —— 不会静默失败，也不会偷偷扣什么。

## 这些功能在哪

> 下面几处**入口以软件内实际位置为准**（版本间可能调整）；
> 找不到时，在对应模块里点带「专业版」标记的按钮即可，会弹出引导 ✓

| 功能 | 大致在哪 |
|---|---|
| 音乐下载 | 音乐相关页面里的下载按钮 |
| 短剧下载 | 短剧下载相关入口（含一个总开关）|
| 短剧其他平台 | **见下方「隐藏入口」**（连点 4 次）|
| 创建 / 激活插件 | 音乐页的「音源」里 |
| 应用伪装 | 「我的」里的伪装相关入口 |
| 外部播放器 | 播放页的更多菜单里 |

### 短剧的隐藏入口（重要）

短剧页面上**看不到**站源/平台相关的设置按钮，它藏在：

> **短剧浏览页 → 左上角的平台名字 → 连点 4 次（2 秒内）**

进去后可以解锁站源管理、切换其它平台。首次需要设置密码；
想省事可以在里面开**无密码模式**（之后点 4 次确认一下就行）。

## 常见问题

**换台电脑还要重新赞助吗？**
不用。在新机器上重新走一次「我已赞助」解锁即可。

**以后会不会变成订阅制？**
不会。承诺是**长期**可用。

**专业版有问题找谁？**
到 [Issues](../../issues) 反馈，标题里注明「专业版」。
