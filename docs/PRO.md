# 风月 · 专业版说明

> 本文档面向**已开启专业版（赞助）**的用户。

## 专业版是什么

专业版是对开发者的**赞助支持**，解锁若干进阶能力。它不是会员制，也没有订阅与到期。

## 怎么开启

在软件里进入专业版入口，按提示完成赞助后**点击「我已赞助」**即可解锁，无需等待审核。

## 专业版能做什么

> 具体能力以软件内实际显示为准（不同版本可能调整）。

- 部分模块的进阶功能与更高配额（例如短剧下载等）
- 界面与体验上的额外选项

## 常见问题

**换了电脑还能用吗？**
可以，重新在软件内解锁即可。

**以后要一直赞助吗？**
不需要，一次支持长期可用。

**有问题找谁？**
到本仓库 [Issues](../../issues) 反馈，注明「专业版」。
