# 风月 · 专业版说明

## 专业版是什么

专业版是对开发者的**赞助支持**，用来解锁若干进阶能力。
它不是会员制，**没有订阅、没有到期**——一次支持，长期可用。

## 怎么开启

在软件里进入**专业版入口**（带「专业版」标记的位置，或按提示弹出的引导），
按提示完成赞助后**点「我已赞助」** ⇒ **立即解锁**，不需要等待审核、也不需要联系谁。

## 哪些功能需要专业版

目前这些能力是专业版专属（**以软件内实际显示为准**，不同版本可能调整）：

| 功能 |
|---|
| 音乐下载 |
| 短剧下载 |
| 短剧更多平台 |
| 创建插件 |
| 激活插件 |
| 外部播放器 |
| 应用伪装 |

> 没解锁时点这些功能会弹出专业版引导，**不会静默失败**。

### 短剧「更多平台」怎么进

短剧页面上看不到相关按钮，入口是：

> **短剧页长按**，或者**连点左上角的平台名 4 次（2 秒内）** ⇒ 即可进入**更多平台**。

> ⚠️ 另外要说明：短剧功能**仅维持短期维护**，**能否长期可用不由本软件决定**。
> 专业版解锁的是「**当前可用的能力**」，**不构成**对短剧长期可用的承诺。

## 常见问题

**换台电脑还要重新赞助吗？**
不用，在新机器上重新走一次「我已赞助」即可。

**以后会变成订阅制吗？**
不会，承诺是**长期**可用。

**专业版有问题找谁？**
到 [Issues](../../issues) 反馈，标题里注明「专业版」。
